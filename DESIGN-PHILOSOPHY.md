# OnsFlow Design Philosophy

## Brand Heritage

**Parent Brand:** 3ons Digital  
**Product:** OnsFlow - Sistem Kasir Digital

---

## Etimologi Nama

### "Ons" (dari 3ons Digital)
| Aspek | Makna |
|-------|-------|
| **On** | Aktif, menyala, terhubung |
| **Transaction** | Transaksi sebagai inti bisnis |
| **Seamless** | Tanpa hambatan, lancar |
| **On us** | Tanggung jawab kami |

### "Flow"
| Konsep | Interpretasi |
|--------|--------------|
| **Aliran** | Tanpa hambatan, mencari jalur termudah |
| **Flow State** | Psychology: keadaan fokus penuh tanpa gesekan |
| **Fluiditas** | Operasional yang lancar dan adaptif |
| **Efisiensi** | Tanpa gesekan, tanpa delay |

## Brand Architecture

```
3ons Digital
├── 3 = Triad (Tech, Design, Business)
├── on = Active state
└── s  = System/Service/Solution
    
    OnsFlow (Extension)
    ├── On = Continuity dari parent brand
    ├── s  = Seamless
    └── Flow = The experience promise
```

---

## Filosofi Inti

> **"Transaction in Flow"**

Transaksi bisnis harus mengalir begitu natural sampai pengguna hampir tidak menyadari teknologinya.

---

## Three Pillars

### 1. On (Aktif & Reliable)
- Selalu aktif 24/7
- Zero downtime commitment
- Real-time synchronization
- Always connected

### 2. Seamless (Tanpa Hambatan)
- Tanpa antrian panjang
- Tanpa learning curve
- Tanpa system lag
- Tanpa friction

### 3. Flow (Pengalaman Natural)
- Intuitive seperti second nature
- Responsive dan cepat
- Adaptive ke kebutuhan user
- Progress without interruption

## Visual Identity Direction

### OnsFlow Color Palette

#### Brand Colors (2 Warna Utama)
| Elemen | Warna | Hex Code | Usage |
|--------|-------|----------|-------|
| **Primary Blue** | Sky Blue | `#4A90E2` | Brand identity, primary actions, links, headers |
| **Accent Pink** | Vibrant Magenta | `#FF6B9D` | CTAs, highlights, active states, flow indicators |

#### Supporting Colors (Sistem Kasir Features)
| Elemen | Warna | Hex Code | Usage |
|--------|-------|----------|-------|
| **Success Green** | Teal/Mint | `#50C878` | Payment success, inventory OK, growth metrics |
| **Alert Red** | Coral Red | `#E85D75` | Low stock, errors, cancellations, refunds |
| **Reward Gold** | Warm Yellow | `#F5A623` | Loyalty points, promotions, premium features |

#### Neutral Palette
- **Neutral Dark** `#1A1A2E` - Text primary
- **Neutral Medium** `#4A4A68` - Text secondary
- **Neutral Light** `#F5F5F7` - Backgrounds
- **White** `#FFFFFF` - Cards, surfaces

### Typography
- **Primary:** Plus Jakarta Sans (20px base)
- **Characteristics:** Modern, geometric, highly legible, contemporary Indonesian design
- **Weights:** Regular (400), Medium (500), SemiBold (600), Bold (700)
- **Usage:** Headlines, UI elements, body text

### Visual Elements
- Fluid shapes (mengalir)
- Subtle animations (flow)
- Generous whitespace (breathing room)
- Micro-interactions (responsiveness)

## User Experience Principles

1. **Zero Friction** - Setiap interaksi harus seamless
2. **Instant Feedback** - Tidak ada operasi tanpa respons
3. **Contextual** - Fitur muncul saat dibutuhkan
4. **Fail-Safe** - Data aman, recovery mudah
5. **Scalable** - Tumbuh bersama bisnis user

## Design System Foundation

### Spacing Scale
Base: 8px  
Scale: 8, 16, 24, 32, 48, 64, 96

### Border Radius
- Small (4px): Buttons, inputs
- Medium (8px): Cards, containers
- Large (16px): Modals, sheets
- Full: Avatars, badges

### Shadow System
- **Level 1:** Subtle elevation (cards)
- **Level 2:** Floating elements (dropdowns)
- **Level 3:** Overlays (modals)
- **Level 4:** Priority (toasts, alerts)
